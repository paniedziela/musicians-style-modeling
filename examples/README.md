# Publiczne przykłady i wyniki

Ten katalog zawiera mały, kontrolowany zestaw artefaktów możliwych do
udostępnienia razem z kodem. Nie zawiera korpusu ASAP, checkpointów, SoundFontu,
cache ani pełnych katalogów eksperymentów.

## Zawartość

- [`e3_bach_prelude/`](e3_bach_prelude/) — krótkie Preludium Bacha BWV 868
  oraz istniejący wynik pełnego E3 `Bach → Beethoven`, jako MIDI i WAV;
- [`e3_kotek/`](e3_kotek/) — krótki lokalny przykład „Kotek” i trzy istniejące
  warianty E3: Bach, Beethoven i Chopin, jako MIDI i WAV;
- [`e2_results/`](e2_results/) — zagregowane podsumowanie i wykresy pełnego
  eksperymentu E2.

Artefakty E2 i wynik dla Preludium powstały z wykorzystaniem danych ASAP
opisanych w [`docs/E1_PLAN.md`](../docs/E1_PLAN.md). Redystrybuowany plik score
MIDI oraz jego adaptacje są oznaczone jako CC BY-NC-SA 4.0 i mają osobne
przypisanie źródła. Przykłady dokumentują działanie techniczne i wyniki
eksperymentów; nie są deklaracją udanego transferu stylu kompozytora.
